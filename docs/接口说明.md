# 蓝图加载接口说明

本工具支持两种从其他页面加载蓝图的方式：

- **URL 接口（`?txt=`）**：给出蓝图代码文件的地址，页面打开时自动下载并解析；
- **postMessage 接口**：宿主页把蓝图文本直接投递进来，不需要下载，也不受 URL 长度限制。

在线地址：<https://hckxv.github.io/DSP-Blueprint-Viewer/>

## 一、URL 接口（`?txt=`）

把蓝图代码文件的地址放进 `?txt=`，打开链接后页面会自动下载文件、按内容判断蓝图类型，并切到对应界面（戴森球预览 / 工厂蓝图）。

### 快速开始

```
https://hckxv.github.io/DSP-Blueprint-Viewer/?txt=蓝图链接
```

把 `蓝图链接` 换成任意蓝图文件地址即可。文件内容以 `DYBP:` 开头会进入戴森球预览，以 `BLUEPRINT:` 开头会进入工厂蓝图。

自建部署时把链接前半段换成自己的站点地址即可，参数名不变。

### 参数

| 参数 | 说明 |
| --- | --- |
| `txt` | 蓝图代码文件的地址，放在 URL 查询串里；不带该参数时页面按正常方式使用 |

注意：

- 值必须是**地址**，不能直接填蓝图代码本身。
- 必须指向**蓝图代码原文**。GitHub 上的文件请使用 `raw.githubusercontent.com` 的地址；`github.com/.../blob/...` 是网页，返回 HTML，会提示「内容不是有效的蓝图代码」。
- 值里含 `&`、`#`、空格等特殊字符时要先 URL 编码，否则会被当成参数分隔符或锚点截断。
- 页面是 https 时不要用 `http://` 地址，会被浏览器按混合内容拦截。

### 地址要求

不限制域名，只要满足下面两点即可：

1. 浏览器能请求到（跨域地址需要目标站点允许 CORS，见下）；
2. 返回的是蓝图文本，而不是网页或二进制文件。

蓝图文件由浏览器直接 `fetch`，不经过工具服务器。

#### 网络地址（跨域）

`txt` 可以直接写完整的 http/https 地址：

```
https://example.com/blueprints/a.txt
```

跨域请求需要目标站点允许跨域（响应带 `Access-Control-Allow-Origin`），否则会提示「加载蓝图失败：Failed to fetch」之类的网络错误；页面是 https 时，`http://` 地址会被浏览器按混合内容拦截。

示例：

```
https://hckxv.github.io/DSP-Blueprint-Viewer/?txt=https://example.com/blueprints/a.txt
```

#### 同源地址

蓝图文件放在本工具站自己的目录下时，可以直接写相对路径或绝对路径，不受跨域限制：

```
https://hckxv.github.io/DSP-Blueprint-Viewer/?txt=./a.txt
```

### 蓝图文件要求

蓝图文件是纯文本，内容必须以以下标记之一开头，区分大小写：

| 开头标记 | 蓝图类型 | 加载后 |
| --- | --- | --- |
| `DYBP:` | 戴森球蓝图 | 切到戴森球预览并解析 |
| `BLUEPRINT:` | 工厂蓝图 | 切到工厂蓝图并解析 |

内容不符合时提示「加载蓝图失败：内容不是有效的蓝图代码」。

### 加载行为

- `?txt=` 在页面打开时读取一次，页面内不会持续监听地址栏。
- 加载结束（成功、失败或参数为空）后会自动从地址栏移除 `txt` 参数；因此刷新页面不会重复加载，要再次加载请重新打开带参数的链接。
- 下载期间会提示「正在加载蓝图」。

### 生成链接

在网页或脚本里拼链接时，对目标地址做一次 `encodeURIComponent` 最稳妥：

```js
const fileUrl = 'https://example.com/blueprints/a.txt'
const link = `https://hckxv.github.io/DSP-Blueprint-Viewer/?txt=${encodeURIComponent(fileUrl)}`
```

## 二、postMessage 接口

其他页面（下称「宿主页」）可以把蓝图文本直接投递给本工具。

### 接入流程

1. 宿主页**先挂上 `message` 监听**，再打开（`window.open`）或嵌入（`<iframe>`）本页；
2. 本页加载完成后，向 `opener` / 父窗口发送 `{ type: 'dsp-blueprint:ready' }`；
3. 宿主收到 ready 后发送 `{ type: 'dsp-blueprint:load', text: 'DYBP:...' }`；
4. 本页解析后回发 `{ type: 'dsp-blueprint:result', ok, message, kind }`。

如宿主错过 ready，可随时向本页发送 `{ type: 'dsp-blueprint:request-ready' }` 请求重新握手，本页会再次向该来源发送 `dsp-blueprint:ready`。

### 消息格式

| 方向 | `type` | 字段 |
| --- | --- | --- |
| 本页 → 宿主 | `dsp-blueprint:ready` | 无 |
| 宿主 → 本页 | `dsp-blueprint:load` | `text`：string，必填，蓝图原文，`DYBP:` 或 `BLUEPRINT:` 开头 |
| 宿主 → 本页 | `dsp-blueprint:request-ready` | 无，请求本页重新发送 `dsp-blueprint:ready` |
| 本页 → 宿主 | `dsp-blueprint:result` | `ok`：boolean；`message`：string；`kind`：`'sphere'` / `'factory'`（内容不合法时没有这个字段） |

- 蓝图种类由开头标记自动判断：`DYBP:` → 球体预览，`BLUEPRINT:` → 工厂预览，不需要也不能另外指定。
- 可以连续发多条 `load`，本页按收到顺序逐条处理。
- 结果与重新握手响应只回给发消息的那个窗口，`targetOrigin` 是它的来源。
- 其他 `type`、缺 `text`、`text` 不是字符串的消息一律忽略。

### 新标签页示例

```js
const VIEWER = 'https://hckxv.github.io/DSP-Blueprint-Viewer/'
const ORIGIN = new URL(VIEWER).origin

let viewer = null
window.addEventListener('message', (event) => {
  if (event.origin !== ORIGIN) return
  const data = event.data
  if (data?.type === 'dsp-blueprint:ready') {
    viewer?.postMessage({ type: 'dsp-blueprint:load', text: blueprintText }, ORIGIN)
  } else if (data?.type === 'dsp-blueprint:result') {
    console.log(data.ok ? '加载成功' : `加载失败：${data.message}`)
  }
})

viewer = window.open(VIEWER, '_blank')
if (!viewer) console.warn('弹窗被浏览器拦截，请把这次打开放到用户点击里')
```

## 维护说明

| 位置 | 作用 |
| --- | --- |
| `src/utils/urlLoader.ts` | `?txt=` 接口：读取参数、下载蓝图原文、加载结束后清理地址栏参数 |
| `src/utils/postMessageBridge.ts` | postMessage 消息类型、消息解析、ready 握手、结果回传 |
| `.env` 的 `VITE_ENABLE_EXTERNAL_LOAD` | 两个外部入口的统一开关（true 开启 / false 关闭）；关闭后 `?txt=` 不加载并清掉参数，postMessage 也不监听 |
| `src/App.vue` 的 `loadUrlBlueprint()` / `startBlueprintMessageBridge()` | 两个入口：URL 加载提示、postMessage 桥的启动与解绑 |
